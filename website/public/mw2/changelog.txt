# 1.0.0-prealpha.1 / pre-alpha1.0.0-COOP - November 15, 2026

Rebuilt the launcher around the supplied compact green military HUD reference:
four-star badge, camo and scanlines, mission concept artwork, custom window
controls, Play / Settings / Info, four player slots and a mission briefing.

Added real six-letter-code hosting/joining, callsigns, four-slot membership,
host-controlled mission and difficulty, periodic roster sync, leave/close and
expiry. Online status and service response time reflect actual requests.

Preserved the existing install detector, exact executable checks and diagnostic
export in Settings. One version.json now controls the compiled label and package.

Four-player gameplay remains unfinished; Launch Game is disabled. Overkill is a
concept mission. Original-game launch remains available in Settings.

# 0.1.0-dev.1 - November 15, 2026

First portable Windows development launcher: Steam detection, manual game path,
exact build validation, private-memory component checks, local diagnostic export,
OPS HUB / source links, and original-game launch through Steam.

Four-player mode is unavailable. The included frame-codec component has only
offline checks; player storage, networking and original mission support are
unfinished. No runtime modification is installed or applied.
