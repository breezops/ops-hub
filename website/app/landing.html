ENGINEERING PROTOCOL

Built like a console feature.

A practical co-op toolkit: direct gameplay networking, isolated test saves, and one place to host, join, and update.

Direct peer-to-peer play

Join codes find your session over HTTPS; gameplay travels directly between PCs over UDP 7777. The host needs port forwarding. Latency depends on your connection; automatic NAT traversal and relay servers are not included.

Host port forwarding Movement smoothing Two-player network tests

Preserves Save Files

Launcher sessions use isolated test saves to keep testing separate from your normal single-player profile. Your latest test settings carry forward between sessions.

SETUP GUIDE

Three steps. Then, together.

01

Download & Extract Launcher

Download and extract the complete ZIP. Keep its files together and open StrayCoop.exe. After this first install, use Check for updates in the launcher.

02

Select Game Folder

Click Browse and point to your main game folder containing Stray.exe. Both players must own/have their own installed copy of Stray.

03

Host or Connect with Code

The Host needs UDP Port 7777 forwarded on their router, clicks Host a Game, and sends their session code. The partner pastes the code and clicks Join.
